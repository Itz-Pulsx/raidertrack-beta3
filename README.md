App name: RaiderTrack
App type: Dining Bucks Planner
Problem being solved: The app addresses the issue of dining plan users struggling with managing their dining bucks. The target users are majority students but facility can also benefit from this app. 
Page 1: Login Page – A Page to login to a users account 
Page 2: Home Page - A Page to navigate to the other pages 
Page 3: Dining Halls Page – A page showcasing all the possible dining options with a dining plan 
Page 4: Transaction History Page- A Page showing where you spent your dining bucks at
Page 5: Dining Planner Page - A page to help plan and manage your dining bucks for the future 
Page 6: Current Dining Bucks Page -  A page to show your  dining bucks balance 
Interactive Feature 1: Dining bucks predictions.  Shows a prediction of how many dining bucks you will use at this current rate
Interactive Feature 2: Search menu. Allows users to search for dining halls and all the features of the app. 
Interactive Feature 3: Animation for login. 
Interactive Feature 4: Drop downs for the dining halls 
Interactive Feature 5: Animation for home page
